MidnightBSD 4.0.6, NetBSD 11.0 RC5, FreeBSD 14.3 EOL and more
<!-- more -->

## Releases
[MidnightBSD 4.0.6 RELEASE](https://bsdsec.net/articles/midnightbsd-security-midnightbsd-4-0-6-release?utm_source=bsdweekly): MidnightBSD 4.0.6 is out with multiple fixes.

[NetBSD 11.0 RC5 available!](https://blog.netbsd.org/tnf/entry/netbsd_11_0_rc5_available?utm_source=bsdweekly): The NetBSD project has released the fifth release candidate for 11.0, urging users to test it before the final release, with updated third-party software like OpenSSL and unbound and split ISO images for CD/R and DVD media.

## BSDSec
[FreeBSD 14.3 end-of-life](https://bsdsec.net/articles/freebsd-14-3-end-of-life?utm_source=bsdweekly): FreeBSD 14.3 reaches end-of-life on June 30, 2026 and will no longer receive security support, with users urged to upgrade to a newer release.

[FreeBSD Security Advisory FreeBSD-SA-26:26.ktls [REVISED]](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-26-ktls-revised?utm_source=bsdweekly): A KTLS receive path flaw allows unprivileged local users to overwrite arbitrary files by sending them over a loopback connection, potentially escalating privileges, and is corrected in all supported FreeBSD branches.

As always, it's worth following [BSDSec](https://bsdsec.net). [RSS feed](https://bsdsec.net/articles.atom) available.

## News
[BSD Now 668: Wiring up the BSDs](https://www.bsdnow.tv/668?utm_source=bsdweekly): This episode covers FreeBSD to OpenBSD WireGuard setups, using object storage with OpenZFS and SeaweedFS, a ZFS script for labeling drives, predictable IPv6 addresses for OpenBSD VMs, and more.

## Tutorials
[The freebsd-update(8) Screensaver](https://vermaden.wordpress.com/2026/06/19/freebsd-update-screensaver/?utm_source=bsdweekly): A terminal screensaver that mimics the freebsd-update(8) tool, released as an Easter Egg for FreeBSD Day, with details on its settings and the project's move to PKGBASE.

[Expand GELI Encrypted Bhyve VM ZFS Disk](https://vermaden.wordpress.com/2026/06/17/expand-geli-encrypted-bhyve-vm-zfs-disk/?utm_source=bsdweekly): A step-by-step guide to expanding a GELI-encrypted ZFS disk for a FreeBSD bhyve VM, covering ZVOL resizing, gpart recovery and partition expansion, GELI auto-resize, and enabling ZFS autoexpand, with notes on FreeBSD 14.1 vs 15.0 behavior.

[ZFS vs Ceph: Do You Actually Need Ceph?](https://klarasystems.com/articles/zfs-vs-ceph-do-you-actually-need-ceph/?utm_source=bsdweekly): Klara Systems compares ZFS and Ceph, explaining when Ceph's distributed storage is necessary and when ZFS offers a simpler, lower-latency, and more cost-effective solution for virtualization, databases, and backups.

[FreeBSD 15 on a Laptop](https://www.sacredheartsc.com/blog/freebsd-15-on-a-laptop/?utm_source=bsdweekly): A detailed walkthrough of setting up FreeBSD 15.1 as a daily-driver laptop OS, covering pkgbase, LinuxKPI WiFi, KDE Plasma 6 on Wayland, battery life, loader/sysctl tuning, device permissions, and hardware-specific tips for ThinkPads.
