## BSDSec
[OpenBSD Errata: July 16, 2026 (elf sysv nfs ipsec)](https://bsdsec.net/articles/openbsd-errata-july-16-2026-elf-sysv-nfs-ipsec?utm_source=bsdweekly): OpenBSD has released errata patches for kernel ELF exec, System V IPC, NFS and IPsec on 7.8 and 7.9, with binary updates available via syspatch for amd64, arm64 and i386.

As always, it's worth following [BSDSec](https://bsdsec.net). [RSS feed](https://bsdsec.net/articles.atom) available.

## News
[Google Summer of Code 2026 Reports: Testing Compat Linux: Syscall testing](https://blog.netbsd.org/tnf/entry/gsoc2026_testing_compat_linux?utm_source=bsdweekly): A GSoC 2026 report by Henrique Brito describes using the Linux Test Project to evaluate NetBSD's compat_linux syscall translation, noting mature POSIX support but gaps with Linux-specific features and edge cases, and includes a package for running LTP on NetBSD.

[OpenBSD relayd(8) adds ECDSA support with CA engine code from smtpd(8)](https://www.undeadly.org/cgi?action=article;sid=20260721124747&utm_source=bsdweekly): relayd(8) now supports ECDSA keys and certificates via a new commit that ports the CA engine code from smtpd(8), resolving prior compatibility issues.

[Code That Built the Internet: The Impact of BSD, Part 1](https://www.lpi.org/blog/2026/06/19/code-that-built-the-internet-the-impact-of-bsd-part-1/?utm_source=bsdweekly): Part one of a two-part series explores how Berkeley's BSD and the internet co-evolved, covering DARPA's role, the creation of Berkeley sockets, and BSD's early implementation of DNS via BIND.

[Valuable News – 2026/07/20](https://vermaden.wordpress.com/2026/07/20/valuable-news-2026-07-20/?utm_source=bsdweekly): This week covers FreeBSD 16 removing the last GPL code from base, OPNsense 26.7 on FreeBSD 15.1, OpenBSD 8.0-beta and upcoming WPA3 support, FreeBSD laptop improvements, a guide to FreeBSD jails with a single public IP, and more.

[WPA3 support coming to OpenBSD](https://www.undeadly.org/cgi?action=article;sid=20260719093851&utm_source=bsdweekly): Stefan Sperling posted a patch to the OpenBSD tech list that adds WPA3 support to the net80211 subsystem and ifconfig, with testing requested and NLnet Foundation funding noted, supporting the revised, side-channel-free WPA3 standard for iwm, iwx, and qwx drivers.

[Understanding the Foundation Board’s Role in the FreeBSD Ecosystem](https://freebsdfoundation.org/blog/understanding-the-foundation-boards-role-in-the-freebsd-ecosystem/?utm_source=bsdweekly): The FreeBSD Foundation explains how its Board is elected, its governance and oversight role, and how it differs from the FreeBSD Project, while welcoming new Board member Dave Cottlehuber.

[FreeBSD Foundation Welcomes New Board Member: Dave Cottlehuber](https://freebsdfoundation.org/blog/freebsd-foundation-welcomes-new-board-member-dave-cottlehuber/?utm_source=bsdweekly): FreeBSD community member and former Core Representative Dave Cottlehuber was elected to the FreeBSD Foundation Board and shares his background with FreeBSD and goals for strengthening connections between the Foundation, developers, and the community.

[OpenBSD moves to 8.0-beta in -current and snapshots](https://www.undeadly.org/cgi?action=article;sid=20260716115231&utm_source=bsdweekly): OpenBSD -current has entered the 8.0-beta phase, marking the start of stabilization for the next release, with snapshots now available for testing.

[OpenBSD/loongson hardware platform retired](https://www.undeadly.org/cgi?action=article;sid=20260716110034&utm_source=bsdweekly): OpenBSD has retired the loongson hardware platform after clang 22 rebuilds hit deterministic SIGSEGV on mips64el, with debugging deemed impractical given long rebuild times and modern ports requiring C++11.

[Represent FreeBSD in Your Community](https://freebsdfoundation.org/blog/represent-freebsd-in-your-community/?utm_source=bsdweekly): The FreeBSD Foundation outlines ways to advocate for FreeBSD, from speaking at meetups and staffing booths to requesting virtual speakers for classes, and offers grants and materials to support community outreach.

[BSD Now 672: Kitchen Calculator](https://www.bsdnow.tv/672?utm_source=bsdweekly): This episode covers Unix pipes under load, the FreeBSD AI-assisted Vulnerability Discovery Project, OpenSSH 10.4/10.4p1 release, OpenBSD's 512GB kernel virtual address space on amd64, and a study on pledge(2) and unveil(2) being developer-friendly.

[g2k26 Hackathon Report: Job Snijders (job@) on rpki-client(8) progress](https://www.undeadly.org/cgi?action=article;sid=20260714094547&utm_source=bsdweekly): Job Snijders describes the g2k26 hackathon in the Netherlands and details his work adding stateful backoff retry logic to rpki-client(8) to reduce pressure on broken RPKI endpoints.

## Tutorials
[(Video) FreeBSD - Using and Configuring a VLAN](https://www.youtube.com/watch?v=uVMe55XOnE8&utm_source=bsdweekly): Video explores how to setup VLANs in FreeBSD, and how to configure the "jump host" machine to provide internet access to the machines connected to a private network, and separated by the individual VLAN.

[Setup a Simple, Self-Hosted Web Server with OpenBSD](https://btxx.org/posts/self-hosted-openbsd/?utm_source=bsdweekly): A practical walkthrough for hosting a website on OpenBSD using httpd, WireGuard for tunneling, and pf for forwarding, with DNS and basic server configuration steps.
