FreeBSD 14.5-BETA1, OpenBSD errata, Enlightenment on NetBSD and more
<!-- more -->

## Releases
[FreeBSD 14.5-BETA1 Now Available](https://lists.freebsd.org/archives/freebsd-stable/2026-August/004267.html?utm_source=bsdweekly): The first beta build for FreeBSD 14.5-RELEASE is available with install images for amd64, i386, powerpc, armv7, aarch64, and riscv64, plus VM, OCI container, and EC2 AMI images, with upgrade instructions via freebsd-update.

## BSDSec
[OpenBSD Errata: August 11, 2026 (npppd iked)](https://bsdsec.net/articles/openbsd-errata-august-11-2026-npppd-iked?utm_source=bsdweekly): Errata patches for npppd and iked have been released for OpenBSD 7.8 and 7.9, with binary updates available via syspatch on amd64, arm64, and i386.

As always, it's worth following [BSDSec](https://bsdsec.net). [RSS feed](https://bsdsec.net/articles.atom) available.

## News
[Google Summer of Code 2026 Reports: Port the Enlightenment desktop environment to NetBSD](https://blog.netbsd.org/tnf/entry/gsoc2026_enlightenment?utm_source=bsdweekly): Dimitris Gounaridis details the progress of porting the Enlightenment desktop to NetBSD via pkgsrc, covering build dependencies, required patches, current issues, and next steps such as upstreaming changes and porting additional Enlightenment software.

[BSD Now 675: Going GPL Free](https://www.bsdnow.tv/675?utm_source=bsdweekly): This episode covers FreeBSD 16 going GPL-free, a new FreeBSD Foundation board member, a proposed m68k port for home-brew machines, and working around dragons with OpenBSD on the Lemote Yeeloong laptop.

## Tutorials
[FreeBSD Storage for OpenShift with Democratic CSI](https://vermaden.wordpress.com/2026/08/09/freebsd-openshift-democratic-csi/?utm_source=bsdweekly): A guide to using FreeBSD with ZFS and NFS as backend storage for OpenShift via the Democratic CSI driver, which issues native ZFS snapshot commands over SSH to avoid slow 1:1 copies.
