## News
[Valuable News – 2026/08/17](https://vermaden.wordpress.com/2026/08/17/valuable-news-2026-08-17/?utm_source=bsdweekly): This week covers FreeBSD 14.5-BETA2, a new video(4) driver in CURRENT, OpenSSH 10.5 release, FreeIPA server on FreeBSD, DTrace memory analyzer, LibreFS on FreeBSD, ZFS jail deployments, Tailscale and Cloudflare tunnels on FreeBSD, and more.

[BSD Now 676](https://www.bsdnow.tv/676?utm_source=bsdweekly): This episode covers the future of the FreeBSD kernel LLDB plugin, BoxyBSD returning to FreeBSD, and GSoC 2026 reports on compat Linux syscall testing, plus more BSD news.

[Code That Built the Internet: The Impact of BSD, Part 2](https://www.lpi.org/blog/2026/06/26/code-that-built-the-internet-the-impact-of-bsd-part-2/?utm_source=bsdweekly): The conclusion of LPI's series covers BSD's role in email via sendmail, its influence on containers through jails, and other contributions such as vi, BPF, termcap, curses, and BSD Make, plus BSD's adoption by companies like Apple and Netflix.

[Code That Built the Internet: The Impact of BSD, Part 1](https://www.lpi.org/blog/2026/06/19/code-that-built-the-internet-the-impact-of-bsd-part-1/?utm_source=bsdweekly): Part one of a two-part series tracing how Berkeley's BSD and the internet co-evolved, from DARPA's choice of BSD for networking to the creation of Berkeley sockets and BIND, which became foundational to the modern internet.

## Tutorials
[Migrating from Codeberg Pages to an OpenBSD VPS](https://nemin.hu/vps/?utm_source=bsdweekly): A detailed walkthrough of replacing Codeberg Pages with a Netcup OpenBSD VPS, covering provider choice, OpenBSD 8.0-beta upgrade, pf firewall setup with rate-limiting, acme-client for TLS, and httpd configuration with HTTP headers and static gzip.

[So Long Relayd, and Thanks for All the Fish](https://btxx.org/posts/so-long-relayd/?utm_source=bsdweekly): OpenBSD -current now lets you set HTTP security headers directly in httpd, eliminating the need to run relayd just for this purpose, and the post shows before-and-after configs.

[FreeBSD Home Server - Part 1: OS Install](https://www.subnetspider.com/2026/08/16/freebsd-home-server-part1.html?utm_source=bsdweekly): A step-by-step guide to installing FreeBSD 15.1-RELEASE, verifying checksums, creating bootable media, and configuring ZFS RAID10, networking, and system hardening before the first reboot.

[Custom FreeBSD UCARP Setup](https://vermaden.wordpress.com/2026/08/15/custom-freebsd-ucarp-setup/?utm_source=bsdweekly): A walkthrough of setting up UCARP on FreeBSD VMs to provide HA with only one IP from a limited /24 subnet, using a shared HA MAC and custom up/down scripts to move the HA IP and MAC between nodes.

[Move FreeBSD System Between ZFS Disks](https://vermaden.wordpress.com/2026/08/14/move-freebsd-between-zfs-disks/?utm_source=bsdweekly): A sysadmin details how they migrated a FreeBSD 15.1-RELEASE installation from a SATA SSD to a ZFS mirror on two NVMe disks using gpart, dd, zpool attach, and detach while the system was running.
