## BSDSec
[FreeBSD Security Advisory FreeBSD-SA-26:63.posixshm](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-63-posixshm?utm_source=bsdweekly): A TOCTOU race in the POSIX shared memory large page configuration can let an unprivileged local user escalate privileges; patches are available for all supported FreeBSD branches and require a reboot.

[FreeBSD Security Advisory FreeBSD-SA-26:62.tty](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-62-tty?utm_source=bsdweekly): A kernel use-after-free in the tty subsystem via TIOCSCTTY ioctl allows an unprivileged local user to escalate privileges; all supported FreeBSD versions are affected and patches are available for 14.4, 15.0, and 15.1 branches.

As always, it's worth following [BSDSec](https://bsdsec.net). [RSS feed](https://bsdsec.net/articles.atom) available.
