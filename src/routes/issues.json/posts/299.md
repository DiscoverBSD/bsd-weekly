## BSDSec
[OpenBGPD 9.3 released](https://bsdsec.net/articles/openbgpd-9-3-released?utm_source=bsdweekly): OpenBGPD 9.3 adds shorthand for the DOWNGRADE BGP community, removes the legacy aspa-set table format, uses getexecpath for privilege separation, and improves graceful restart timer handling for multi-AFI/SAFI sessions.

[OpenBSD Errata: September 30, 2026 (nsd unbound libressl procargs sysvipc iked wgbind sysvsem uidrange)](https://bsdsec.net/articles/openbsd-errata-september-30-2026-nsd-unbound-libressl-procargs-sysvipc-iked-wgbind-sysvsem-uidrange?utm_source=bsdweekly): OpenBSD has released errata patches for OpenBSD 7.8 and 7.9 covering NSD, unbound, LibreSSL, iked, the kernel, and several base utilities, available as binary updates via syspatch on amd64, arm64, and i386.

[FreeBSD Security Advisory FreeBSD-SA-26:69.udp](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-69-udp?utm_source=bsdweekly): A vulnerability in the IPv6 UDP send path allows processes in classic non-VNET jails to send datagrams to services listening on the host's loopback address, bypassing network isolation. All supported FreeBSD versions are affected, and updates are available via pkg, freebsd-update, and source patches.

[FreeBSD Security Advisory FreeBSD-SA-26:68.openssl](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-68-openssl?utm_source=bsdweekly): FreeBSD has issued a security advisory for an out-of-bounds read in OpenSSL DTLS retransmission (CVE-2026-84782) affecting all supported FreeBSD versions, which may disclose heap memory or cause a DoS, with patches available for 14.x and 15.x branches.

[FreeBSD Security Advisory FreeBSD-SA-26:67.ktls](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-67-ktls?utm_source=bsdweekly): FreeBSD has issued a security advisory for an off-by-one bug in receive-side kernel TLS (KTLS) handling of TLS 1.3 payloads. A remote attacker sending an invalid frame can trigger an underflow and NULL pointer dereference, causing a kernel panic and denial of service.

[FreeBSD Security Advisory FreeBSD-SA-26:66.jail](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-66-jail?utm_source=bsdweekly): FreeBSD has issued a security advisory addressing three vulnerabilities in jail directory file descriptor handling that allow processes to bypass restriction flags and escape the jail filesystem root.

[FreeBSD Security Advisory FreeBSD-SA-26:65.kqueue](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-65-kqueue?utm_source=bsdweekly): FreeBSD has issued a security advisory for two memory safety vulnerabilities in kqueue's copy-on-fork implementation that could allow an unprivileged local user to escalate privileges on FreeBSD 15.1.

[FreeBSD Security Advisory FreeBSD-SA-26:64.sysvsem](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-64-sysvsem?utm_source=bsdweekly): A heap out-of-bounds access in semop(2) allows an unprivileged local user to potentially escalate privileges due to a 15-bit sequence number wrap-around in System V semaphores, affecting all supported FreeBSD versions; patches and update instructions are provided.

[FreeBSD Errata Notice FreeBSD-EN-26:24.tzdata](https://bsdsec.net/articles/freebsd-errata-notice-freebsd-en-26-24-tzdata?utm_source=bsdweekly): FreeBSD has issued an errata notice updating the IANA Time Zone Database files in /usr/share/zoneinfo across all supported release branches.

[FreeBSD Errata Notice FreeBSD-EN-26:23.syslogd](https://bsdsec.net/articles/freebsd-errata-notice-freebsd-en-26-23-syslogd?utm_source=bsdweekly): FreeBSD has issued an errata notice for syslogd(8) to fix a process descriptor leak occurring on SIGHUP configuration reloads when logging to pipe destinations, which could leave un-reaped zombie processes or cause daemon crashes.

[FreeBSD Errata Notice FreeBSD-EN-26:22.usb](https://bsdsec.net/articles/freebsd-errata-notice-freebsd-en-26-22-usb?utm_source=bsdweekly): FreeBSD has published an errata notice for FreeBSD 14.5 fixing a regression in xhci(4) that prevents some umass(4) USB mass storage devices from attaching.

As always, it's worth following [BSDSec](https://bsdsec.net). [RSS feed](https://bsdsec.net/articles.atom) available.

## News
[Production Deployments](https://freebsdfoundation.org/our-work/journal/browser-based-edition/production-deployments/?utm_source=bsdweekly): The FreeBSD Journal's latest issue includes articles on consolidating a home lab with Sylve, cloud operations using FreeBSD Compute, USB in user space, and auditable credential-exposure checks on FreeBSD.

[LibreSSL 4.4.0rc1 released](https://bsdsec.net/articles/libressl-4-4-0rc1-released?utm_source=bsdweekly): LibreSSL 4.4.0rc1 is a development release for the 4.4.x branch with portable fixes for AIX, macOS, MSVC, and Windows, internal improvements to DTLS, TLS 1.3, and SHA-3, compatibility updates for libtls and OpenSSL, and multiple bug and security fixes including X.509 name constraints URI parsing and DTLS handshake message size limits.

[LibreSSL 4.2.2 and 4.3.3 released](https://bsdsec.net/articles/libressl-4-2-2-and-4-3-3-released?utm_source=bsdweekly): LibreSSL versions 4.2.2 and 4.3.3 address an OCSP responder authorization bypass in libtls, DTLS fragment and buffer handling issues, and X.509 certificate verification bugs alongside build fixes for macOS and MSVC ARM64.

[Valuable News - 2026/10/05](https://vermaden.wordpress.com/2026/10/05/valuable-news-2026-10-05/?utm_source=bsdweekly): This week's BSD roundup covers GhostBSD's new Mocka desktop project, FreeBSD bring-up on Apple M6 hardware, OpenBSD developers rejecting a uutils coreutils port over licensing concerns, updates to OpenBSD relayd and httpd, NetBSD's GSoC work on Racoon2, and more.

[October 2026 Update: Getting Ready for the EU Cyber Resilience Act](https://freebsdfoundation.org/blog/october-2026-update-getting-ready-for-the-eu-cyber-resilience-act/?utm_source=bsdweekly): The FreeBSD Foundation outlines its CRA Readiness project progress, including manufacturer outreach, steward obligations, SBOM tooling for FreeBSD 14-16, Security Team support, and community resources like guides and a dedicated CRA email address.

[Improving and Stabilizing the racoon2 IKE Daemon in NetBSD](https://blog.netbsd.org/tnf/entry/gsoc2026_racoon2?utm_source=bsdweekly): A Google Summer of Code 2026 report details recent work on NetBSD's racoon2 IPsec daemon to make it a reliable VPN server for modern clients. The updates bring RFC-compliant IKE fragmentation, NAT traversal with address substitution, fixed IPv6 support enabled by default, unified wildcard address macros, and an automated unit testing framework.

[What's New in httpd and relayd](https://rsadowski.de/posts/2026/update-relayd-and-httpd/?utm_source=bsdweekly): Author details recent updates to OpenBSD's httpd and relayd, including custom HTTP response header manipulation and request filtering via new header block and drop rules in httpd. The post also covers patterns(7) expression support in relayd for advanced matching in filter rules.

[OpenBGPD 9.3 released](https://www.undeadly.org/cgi?action=article;sid=20261001164002&utm_source=bsdweekly): OpenBGPD 9.3 adds a shorthand for the "DOWNGRADE" BGP community, drops the old aspa-set table format, improves graceful restart timer handling, and fixes edge cases in ASPA updates, with portable builds confirmed on FreeBSD and several Linux distributions.

[BSD Now 683: GeFS (GeFUS)](https://www.bsdnow.tv/683?utm_source=bsdweekly): Episode 683 of BSD Now covers early previews of the GeFS file system on OpenBSD, the release of NetBSD 9.5, the OpenSMTPD 7.9.0p0 release, replacing pam-ssh-agent-auth in FreeBSD ports, and more.

[OpenBSD -current is now "8.0-current"](https://www.undeadly.org/cgi?action=article;sid=20261001091454&utm_source=bsdweekly): Theo de Raadt updated OpenBSD -current from "8.0" to "8.0-current", so users on the latest snapshots or source builds no longer need "-D snap" with pkg_add and pkg_info.

[EuroBSDCon 2026 in Brussels, Belgium: travel notes after the conference](https://blog.netbsd.org/tnf/entry/eurobsdcon_2026_in_brussels_belgium?utm_source=bsdweekly): A NetBSD developer recounts EuroBSDCon 2026, covering the NetBSD Summit talks on fss(4) snapshots, VCS migration to Mercurial/Git, jj VCS, running NetBSD on Wii U, GSoC 2026 projects, and social events with the BSD community.

[FreeBSD Release Cycles and Enterprise Requirements: Why LTS Matters](https://klarasystems.com/articles/freebsd-release-cycles-enterprise-requirements-lts/?utm_source=bsdweekly): Klara examines the gap between FreeBSD's standard support lifecycle and enterprise hardware or appliance lifecycles. The article discusses how long-term support separates security patching from major upgrade schedules and outlines Klara's commercial FreeBSD LTS offering.
