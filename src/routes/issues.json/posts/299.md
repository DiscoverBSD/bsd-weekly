## BSDSec
[FreeBSD 15.0 end-of-life](https://bsdsec.net/articles/freebsd-15-0-end-of-life?utm_source=bsdweekly): FreeBSD 15.0 reaches end-of-life on September 30, 2026, after which it will no longer receive security updates from the FreeBSD Security Team.

As always, it's worth following [BSDSec](https://bsdsec.net). [RSS feed](https://bsdsec.net/articles.atom) available.

## News
[Valuable News – 2026/09/28](https://vermaden.wordpress.com/2026/09/28/valuable-news-2026-09-28/?utm_source=bsdweekly): This week's roundup covers the release of NetBSD 10.2, OpenBSD-current moving to 8.0, and OpenBSD adding multi-processor support to vmm/vmd alongside a new rtrd daemon. FreeBSD topics include launching KDE Desktop AMIs on AWS EC2, a guide to common ZFS misconfigurations, the new kldinfo utility for inspecting kernel module dependencies, and native Brave browser support.

[HardenedBSD August / September 2026 Status Report](https://hardenedbsd.org/article/shawn-webb/2026-09-27/hardenedbsd-august-september-2026-status-report?utm_source=bsdweekly): HardenedBSD's latest status report highlights release engineering prep for quarterly builds, base OS updates including experimental -fbounds-safety support and hardened SSH defaults, and infrastructure migrations from VMs to jails. It also details restored GitHub repository mirroring and the project's stance on recent Radicle network security disclosures.

[OpenBSD -current has moved to version 8.0](https://www.undeadly.org/cgi?action=article;sid=20260927120854&utm_source=bsdweekly): Theo de Raadt has moved OpenBSD -current to version 8.0, dropping the beta tag as part of the standard pre-release process, and reminds users to use "-D snap" with pkg_add and to test and report issues.

[OpenBSD Gains New Networking Daemon: rtrd(8)](https://www.undeadly.org/cgi?action=article;sid=20260927120124&utm_source=bsdweekly): OpenBSD has imported rtrd(8) and rtrctl(8), an RPKI-To-Router protocol implementation created by Ralph Covelli. The daemon acts as a distribution layer to deliver data from rpki-client(8) to BGP routers such as bgpd(8).

[vmm(4)/vmd(8) gain support for multi-processor VMs](https://www.undeadly.org/cgi?action=article;sid=20260927115632&utm_source=bsdweekly): Mike Larkin added multi-processor guest support to OpenBSD's vmm(4)/vmd(8), implementing the SIPI/init LAPIC state machine, MP IPI support, and new vmctl/vm.conf options, tested on various guests.

[BSD Now 682: NAS NAS NAS](https://www.bsdnow.tv/682?utm_source=bsdweekly): This episode covers new BSD-based NAS projects (BSDNAS, FreeCORE), a FreeBSD Foundation intern working on ROCm support, OpenSSH 10.5, and a look at the OpenBSD -fret-clean flag.

## Tutorials
[What about ThinkCentre M710q, M720q and *BSD](https://www.tumfatig.net/2026/what-about-thinkcentre-m710q-m720q-and-bsd/?utm_source=bsdweekly): A hands-on comparison of Lenovo ThinkCentre M710q and M720q mini PCs running OpenBSD 7.9, NetBSD 11.0, and FreeBSD 15.1, with idle and load power measurements, CPU frequency scaling notes, and observations on headless operation and media playback.

[Installing Ubuntu 26.04 Server in an OpenBSD vmm(4) VM](https://rsadowski.de/posts/2026/vmm-ubuntu26-setup/?utm_source=bsdweekly): A step-by-step guide to rebuilding the Ubuntu Server ISO with modified GRUB and kernel options so it boots and installs cleanly on OpenBSD's serial-only vmm console.

[Biggest ZFS Misconfigurations and How to Fix Them: Part 1](https://klarasystems.com/articles/zfs-misconfigurations-how-to-fix-part-1/?utm_source=bsdweekly): Klara Systems explains how to identify and fix common ZFS misconfigurations involving ashift, recordsize, vdev layout, dedup, and pool capacity, with practical examples and commands.
