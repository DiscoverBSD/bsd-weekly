## Releases
[First Test Version of FuguIta 8.0 Available](https://fuguita.org/?FuguIta/8.0&utm_source=bsdweekly): FuguIta has released its first test version based on OpenBSD 8.0 for i386, incorporating OpenBSD 8.0 errata patches up to 005.

## BSDSec
[LibreSSL 4.3.4 and 4.2.3 released](https://bsdsec.net/articles/libressl-4-3-4-and-4-2-3-released?utm_source=bsdweekly): LibreSSL 4.3.4 and 4.2.3 remove the eMudhra emSign ECC Root CA - G3 certificate from cert.pem due to weak subordinate CA keys while adding uncompromised intermediates for interoperability.

[LibreSSL 4.4.0 released](https://bsdsec.net/articles/libressl-4-4-0-released?utm_source=bsdweekly): LibreSSL 4.4.0 is the first stable release of the 4.4.x branch, shipping with OpenBSD 8.0. Key changes include removing a root CA with weak keys, fixing an OCSP responder authorization bypass in libtls, improving DTLS and TLS 1.3 handling, and updating portable builds for FreeBSD, NetBSD, macOS, and Windows.

[OpenBSD Errata: October 23, 2026 (dbupdate)](https://bsdsec.net/articles/openbsd-errata-october-23-2026-dbupdate?utm_source=bsdweekly): OpenBSD has released errata patches containing a new dbupdate tool and updated cert.pem file for OpenBSD 7.9 and 8.0, with binary updates available via syspatch on amd64, arm64, and i386.

[eMudhra TLS/SSL CA compromise](https://blog.netbsd.org/tnf/entry/emudhra_tls_ssl_ca_compromise?utm_source=bsdweekly): NetBSD shipped eMudhra CA certificates by default and now revokes trust in them due to compromise, with instructions to run certctl untrust for affected certs on NetBSD 10+ and guidance for pkgsrc mozilla-rootcerts users.

[FreeBSD Security Advisory FreeBSD-SA-26:73.caroot](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-73-caroot?utm_source=bsdweekly): FreeBSD has updated its caroot root certificate bundle to mark the emSign ECC Root CA - G3 certificate as untrusted following the public disclosure of compromised eMudhra intermediate keys.

As always, it's worth following [BSDSec](https://bsdsec.net). [RSS feed](https://bsdsec.net/articles.atom) available.

## News
[Valuable News – 2026/10/26](https://vermaden.wordpress.com/2026/10/26/valuable-news-2026-10-26/?utm_source=bsdweekly): Highlights include the release of OpenBSD 8.0 and LibreSSL 4.4.0, a port of Wine to OpenBSD, running FreeBSD ARM64 on Apple Silicon with Cube, and configuring encrypted root on NetBSD 11. Additional items cover the bob pkgsrc package builder, running Signal Desktop on FreeBSD, and NetBSD's eMudhra CA compromise.

[BSD Now 686: Yell in your Shell](https://www.bsdnow.tv/686?utm_source=bsdweekly): Episode 686 covers shell exclamation mark usage, OpenBSD adding the rtrd(8) networking daemon and multi-processor VM support in vmm/vmd, OpenBGPD 9.3, running BSD on Lenovo ThinkCentre hardware, and more.

[emulators/wine (re)entering OpenBSD ports](https://www.undeadly.org/cgi?action=article;sid=20261022052106&utm_source=bsdweekly): Thomas Frohwein submitted a proposal for a new emulators/wine port to run Windows binaries on OpenBSD, alongside a supplementary emulators/wine-extras port for winetricks and wine-steam.

[dbupdate(8) Added to OpenBSD -current](https://www.undeadly.org/cgi?action=article;sid=20261021191736&utm_source=bsdweekly): OpenBSD -current has added dbupdate(8), a new utility for updating signed zoneinfo and cert.pem databases from cdn.openbsd.org. Designed to run via root cron, it provides a way to update timezone and CA certificate files without relying on sequential syspatch updates.

## Tutorials
[Your AI Configured Your ZFS. Are You Sure That's Right?](https://klarasystems.com/articles/ai-generated-zfs-configuration-is-it-right/?utm_source=bsdweekly): Klara Systems examines common pitfalls in AI-generated ZFS configurations, such as wrong ashift values, disabled synchronous writes, and feature upgrades that break host compatibility.
