## Releases
[GhostBSD 26.3.R15.1p6 Is Now Available](https://ghostbsd.org/news/GhostBSD_26.3.R15.1p6_Is_Now_Available?utm_source=bsdweekly): GhostBSD 26.3.R15.1p6 is a bug fix release based on FreeBSD 15.1 p6 that addresses leftover NVIDIA repository files on fresh installations. It also introduces a dotted versioning format so pkg properly compares GhostBSD release numbers.

[NetBSD 11.1 released](https://blog.netbsd.org/tnf/entry/netbsd_11_1_released?utm_source=bsdweekly): NetBSD 11.1 is out with security updates for mozilla-rootcerts, brotli, xorg-server, hdaudio, compat_linux, unbound, and ipfilter, plus fixes for USB stability on Raspberry Pi, hot-plugging in USB Wi-Fi drivers, battery monitoring on Surface Go 3, and support for Zhaoxin KX-7000 CPUs and Sun Ultra/Sun Fire sensors.

## BSDSec
[OpenBSD Errata: November 5, 2026 (isakmpd xlibs pffq unveil)](https://bsdsec.net/articles/openbsd-errata-november-5-2026-isakmpd-xlibs-pffq-unveil?utm_source=bsdweekly): OpenBSD has released errata patches for isakmpd, the X11 libraries, pf FQ-CoDel, and unveil kernel code on OpenBSD 7.9 and 8.0, available via syspatch for amd64, arm64, and i386.

As always, it's worth following [BSDSec](https://bsdsec.net). [RSS feed](https://bsdsec.net/articles.atom) available.

## News
[New FreeBSD pkgbase-update(8) Tool](https://vermaden.wordpress.com/2026/11/10/freebsd-pkgbase-update-tool/?utm_source=bsdweekly): A new shell script replaces freebsd-update(8) for PKGBASE-based upgrades, offering commands like upgrade, install, loader, pkgnew, and modules to automate base system updates for FreeBSD 16 and beyond.

[Valuable News – 2026/11/09](https://vermaden.wordpress.com/2026/11/09/valuable-news-2026-11-09/?utm_source=bsdweekly): This week covers FreeBSD 15.2-BETA1 with experimental PKGBASE cross builds, NetBSD 11.1 release, GhostBSD 26.2 with a friendlier installer and GELI encryption, OpenBSD top adding chroot/pledge/unveil status, FreeBSD bhyve running VMs in one process, and more.

[No sshhole for DragonFly](https://www.dragonflydigest.com/2026/11/06/no-sshhole-for-dragonfly/?utm_source=bsdweekly): DragonFly BSD is not vulnerable to the newly disclosed SSHhole issue, and the author suspects other BSDs are also unaffected.

[OpenBSD top(1) adds flag to show chroot, pledge and unveil status](https://www.undeadly.org/cgi?action=article;sid=20261106104957&utm_source=bsdweekly): OpenBSD has updated top(1) with a new -Q flag to display whether processes are using chroot, pledge, and unveil. The feature shows pledge promises alongside command names and adds state letters for security restrictions in the PRIV column.

[BSD Now 688: Eighty](https://www.bsdnow.tv/688?utm_source=bsdweekly): This episode covers OpenBSD 8.0 release highlights including vmd multi-CPU support and Clang 22, a guide on fixing ZFS misconfigurations, and WebZFS Beta3. Additional topics include recent HardenedBSD updates, NetBSD surpassing its 2026 fundraising goal, and Wine re-entering OpenBSD ports.

[OpenSSH 10.6p2 Released](https://www.undeadly.org/cgi?action=article;sid=20261105104042&utm_source=bsdweekly): OpenSSH 10.6p2 adds a mitigation for a password authentication bypass affecting musl-based Linux systems without PAM, alongside bugfixes such as enabling post-quantum signatures for CAs. The development team also announced plans for more frequent releases to ship security fixes faster in response to rapid AI bug rediscovery.

[PHP and DragonFly](https://www.dragonflydigest.com/2026/11/03/php-and-dragonfly/?utm_source=bsdweekly): A new DragonFly BSD package build is on the way to address the PHP2Shell vulnerability, which will likely be followed shortly by the DragonFly 6.6 release.

## Tutorials
[Why Enterprise FreeBSD Deployments Need Long-Term Support](https://klarasystems.com/articles/why-enterprise-freebsd-deployments-need-long-term-support/?utm_source=bsdweekly): Klara Systems explains the gap between FreeBSD's standard support cycle and the 7–10 year lifespan of enterprise deployments. The article covers how short upgrade windows risk security or drive migrations to Linux, and how commercial long-term support bridges the gap.
