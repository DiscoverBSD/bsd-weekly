## News
[NeoBSD](https://neobsd.com/?utm_source=bsdweekly): NeoBSD is an independent custom NetBSD build that continuously integrates Cells for NetBSD to provide kernel-enforced, jail-like container isolation. It offers ready-to-use release images along with build scripts and patches to generate builds directly from vanilla NetBSD sources.

[Valuable News - 2026/11/16](https://vermaden.wordpress.com/2026/11/16/valuable-news-2026-11-16/?utm_source=bsdweekly): This week's roundup covers FreeBSD 15.2-BETA2 and the 2026 Q3 status report, VM live migration in bhyve, NetBSD 11 on Raspberry Pi 4, pledge and unveil status flags in OpenBSD top(1), Game of Trees 0.131, and more.

[The latest FreeBSD report is here, and the AI debate is ongoing](https://www.theregister.com/os-platforms/2026/11/12/the-latest-freebsd-report-is-here-and-the-ai-debate-is-ongoing/5309206?utm_source=bsdweekly): The Register reviews the FreeBSD Q3 2026 status report, highlighting progress on projects like the Sylve virtualization GUI and the AppJail container tool. The report also details a developer survey where 88 percent of respondents favored establishing a policy on AI-generated code contributions.

[BSD Now 689: Start, restart, stop](https://www.bsdnow.tv/689?utm_source=bsdweekly): This episode covers the biggest ZFS misconfigurations and fixes, a deep dive into FreeBSD's rc.d service framework, progress on OpenBSD's GEFS, LibreSSL 4.4.0/4.3.4/4.2.3 releases, and more.

[New names in the BSD family](https://hovancik.net/blog/2026/11/12/new-names-in-the-bsd-family/?utm_source=bsdweekly): A roundup of recent and revived BSD projects created or restarted since 2022. Highlights include FreeBSD desktop setups like Daemonarchy and HyprBSD, TrueNAS CORE continuations FreeCORE and BSDnas, minimal NetBSD VM toolkit smolBSD, NixBSD, and the PureDarwin revival.

[LibreSSL 4.3.5 and 4.4.1 released](https://bsdsec.net/articles/libressl-4-3-5-and-4-4-1-released?utm_source=bsdweekly): LibreSSL 4.4.1 fixes an out-of-bounds read during TLSv1.2 renegotiation and an interoperability issue with peers sending more than 32 signature algorithms, which is also included in version 4.3.5.

[DPorts 2026Q4 Packages for DragonFly 6.4 and 6.5](https://lists.dragonflybsd.org/pipermail/users/2026-November/452649.html?utm_source=bsdweekly): DragonFly BSD has made work-in-progress binary packages built from DPorts 2026Q4 available for versions 6.4 and 6.5. This update bumps pkg to 2.8 and refreshes thousands of packages from the previous 2025Q2 set, though base system prerequisites apply and certain ports are not yet available.

[FreeBSD Status Report Third Quarter 2026](https://www.freebsd.org/status/report-2026-07-2026-09/?utm_source=bsdweekly): The FreeBSD Project's Q3 2026 status report details 51 updates across core governance, infrastructure, and core technical projects. Key highlights include developer survey results on AI tool usage, rewriting ports Git history to remove an accidentally committed binary, and release engineering updates for FreeBSD 14.5 and 15.2. Developer reports cover bhyve enhancements, kernel bounds-safety adoption, ROCm support, audio stack updates, and improved wireless networking support.

## Tutorials
[ZFS Metrics That Matter for Database Performance](https://klarasystems.com/articles/zfs-storage-metrics-database-performance/?utm_source=bsdweekly): Klara Systems explains how to diagnose PostgreSQL and MySQL database bottlenecks on OpenZFS using four metrics: sync write latency, ARC demand hit ratio, I/O amplification, and queue depth. The guide includes database-specific ZFS dataset tunings, such as turning off redundant full page writes in PostgreSQL and disabling doublewrite buffers in InnoDB.

[NetBSD 11 Desktop on a Raspberry Pi 4](https://neongd.com/articles/netbsd11-rpi4.gmi?utm_source=bsdweekly): This guide covers installing NetBSD 11 arm64 on a Raspberry Pi 4 using UEFI firmware, fixing the bwfm Wi-Fi driver firmware symlink, and setting up the CDE-style NsCDE desktop environment.
