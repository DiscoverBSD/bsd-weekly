## Releases
[FreeBSD 15.2-BETA3 Now Available](https://lists.freebsd.org/archives/freebsd-stable/2026-November/004393.html?utm_source=bsdweekly): FreeBSD has released the third beta build of the 15.2 release cycle. Changes since BETA2 include MIT Kerberos 1.22.3, OpenZFS fixes for block cloning and Direct I/O, a per-minor-version kmods package repository, and recent security advisories.

## BSDSec
[OpenBSD Errata: November 19, 2026 (xfontlibs pty kqueue)](https://bsdsec.net/articles/openbsd-errata-november-19-2026-xfontlibs-pty-kqueue?utm_source=bsdweekly): OpenBSD 7.9 and 8.0 have received errata patches for X11 font libraries along with kernel pty and kqueue interfaces, with binary updates available via syspatch for amd64, arm64, and i386.

[FreeBSD Security Advisory FreeBSD-SA-26:93.tcp](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-93-tcp?utm_source=bsdweekly): A local privilege escalation vulnerability in FreeBSD's TCP MSG_OOB handling allows an unprivileged user to modify cached file contents and gain superuser privileges, affecting all supported FreeBSD versions; patches and update instructions are provided.

[FreeBSD Security Advisory FreeBSD-SA-26:92.vfs](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-92-vfs?utm_source=bsdweekly): A directory permission bypass in open(2) allows unprivileged local users to list directory contents or access files within directories they lack read or search permissions for, affecting all supported FreeBSD versions and corrected in stable/15, releng/15.1, stable/14, releng/14.5, and releng/14.4.

[FreeBSD Security Advisory FreeBSD-SA-26:91.fdescfs](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-91-fdescfs?utm_source=bsdweekly): fdescfs(4) lacks access checks and fails to verify write permissions, letting unprivileged local users truncate or extend any file they can open read-only, enabling privilege escalation or DoS; patches are available for all supported FreeBSD versions.

[FreeBSD Security Advisory FreeBSD-SA-26:90.vm](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-90-vm?utm_source=bsdweekly): A privilege escalation vulnerability in FreeBSD's prefaulting code for largepage mappings allows an unprivileged local user to access freed physical memory and escalate privileges, affecting all supported versions.

[FreeBSD Security Advisory FreeBSD-SA-26:89.bsnmp](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-89-bsnmp?utm_source=bsdweekly): FreeBSD has issued a security advisory for bsnmpd(1) detailing multiple vulnerabilities, including skipped USM authentication and VACM checks for SNMPv3 discovery requests (CVE-2026-127742) and a heap buffer overflow in the VACM module (CVE-2026-127743), affecting all supported FreeBSD versions.

[FreeBSD Security Advisory FreeBSD-SA-26:88.sound](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-88-sound?utm_source=bsdweekly): A privilege escalation vulnerability in FreeBSD's sound(4) driver allows a local unprivileged user to trigger a use-after-free via a race condition during buffer resizing, affecting all supported FreeBSD versions and corrected in stable/15, releng/15.1, stable/14, releng/14.5, and releng/14.4.

[FreeBSD Security Advisory FreeBSD-SA-26:87.socket](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-87-socket?utm_source=bsdweekly): A use-after-free in the SO_SPLICE socket option's idle timeout handler can allow an unprivileged local user to escalate privileges on all supported FreeBSD versions; patches and updated binaries are available for 14.4, 14.5, 15.1, and stable/14 and stable/15.

[FreeBSD Security Advisory FreeBSD-SA-26:86.freebsd32](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-86-freebsd32?utm_source=bsdweekly): FreeBSD has patched a local privilege escalation vulnerability in the compat32 subsystem where race conditions during recvmsg(2) control message processing with MSG_PEEK could corrupt socket memory.

[FreeBSD Security Advisory FreeBSD-SA-26:85.kqueue](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-85-kqueue?utm_source=bsdweekly): FreeBSD has issued a security advisory for multiple vulnerabilities in kevent(2) affecting all supported versions, including a race condition in EVFILT_TIMER that can lead to privilege escalation and a KQUEUE_CPONFORK race in fork(2) that corrupts kernel memory.

[FreeBSD Security Advisory FreeBSD-SA-26:84.vmm](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-84-vmm?utm_source=bsdweekly): FreeBSD has issued a security advisory for bhyve's vmm module, fixing a vulnerability on Intel CPUs where privileged guest software can trigger a host kernel panic by writing invalid values to the IA32_TSC_AUX MSR.

[FreeBSD Security Advisory FreeBSD-SA-26:83.unix](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-83-unix?utm_source=bsdweekly): FreeBSD has issued a security advisory for a race condition between shutdown(2) and listen(2) on UNIX domain sockets that allows unprivileged local users to trigger memory corruption and escalate privileges.

[FreeBSD Security Advisory FreeBSD-SA-26:82.ipsec](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-82-ipsec?utm_source=bsdweekly): FreeBSD has patched an IPsec vulnerability (CVE-2026-101318) caused by incorrect locking in esp_output(), which could lead to initialization vector reuse across concurrent packet transmissions. An on-path attacker could exploit this flaw to recover plaintext or tamper with intercepted packets.

[FreeBSD Security Advisory FreeBSD-SA-26:81.vfs](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-81-vfs?utm_source=bsdweekly): FreeBSD 15.1 has a Capsicum and O_RESOLVE_BENEATH bypass at mount roots that lets sandboxed processes escape to the parent of the mount point; patches are available for stable/15 and releng/15.1.

[FreeBSD Security Advisory FreeBSD-SA-26:80.vfs](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-80-vfs?utm_source=bsdweekly): A privilege escalation vulnerability in FreeBSD's inotify implementation allows a local unprivileged user to trigger a use-after-free via watch descriptor wraparound, potentially gaining full system control. Affected versions are FreeBSD 15.1 and 14.5, with patches available for stable/15, releng/15.1, stable/14, and releng/14.5.

[FreeBSD Security Advisory FreeBSD-SA-26:79.nfs](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-79-nfs?utm_source=bsdweekly): FreeBSD has issued a security advisory for a NFSv4 server vulnerability (CVE-2026-101317) allowing remote code execution via stateid type confusion, affecting all supported versions with patches available for stable/15, releng/15.1, stable/14, releng/14.5, and releng/14.4.

[FreeBSD Security Advisory FreeBSD-SA-26:78.gssd](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-78-gssd?utm_source=bsdweekly): gssd in FreeBSD 15.1 maps unrecognized Kerberos principals to UID 0, allowing remote users with valid Kerberos credentials to gain superuser access on NFS servers using Kerberos security; patches and updates are available.

[FreeBSD Security Advisory FreeBSD-SA-26:76.ocs_fc](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-76-ocs_fc?utm_source=bsdweekly): FreeBSD has issued a security advisory for multiple vulnerabilities in the ocs_fc(4) Fibre Channel driver, including insufficient ioctl validation, out-of-bounds memory access, and use-after-free, affecting all supported FreeBSD versions.

[FreeBSD Security Advisory FreeBSD-SA-26:75.linux](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-75-linux?utm_source=bsdweekly): The Linuxulator's listxattr() implementation in FreeBSD has a kernel memory disclosure vulnerability (CVE-2026-101314) allowing unprivileged local users to read kernel memory or trigger a DoS, with patches available for all supported releases.

[FreeBSD Security Advisory FreeBSD-SA-26:74.ktls](https://bsdsec.net/articles/freebsd-security-advisory-freebsd-sa-26-74-ktls?utm_source=bsdweekly): FreeBSD has issued a security advisory for a bug in KTLS control message parsing where insufficient size validation allows a local user to expose one byte of uninitialized kernel memory in outgoing TLS records.

[FreeBSD Errata Notice FreeBSD-EN-26:32.zfs](https://bsdsec.net/articles/freebsd-errata-notice-freebsd-en-26-32-zfs?utm_source=bsdweekly): FreeBSD has issued an errata for OpenZFS data corruption involving pending block frees on FreeBSD 15.1, with fixes available in 15.1-RELEASE-p7 and stable/15 as of Nov 14-17, 2026.

[FreeBSD Errata Notice FreeBSD-EN-26:31.openssl](https://bsdsec.net/articles/freebsd-errata-notice-freebsd-en-26-31-openssl?utm_source=bsdweekly): FreeBSD has updated base system OpenSSL to 3.0.22 on FreeBSD 14 and 3.5.9 on FreeBSD 15 to resolve multiple security issues, including QUIC denial-of-service vulnerabilities, AEAD tag forgery, and timing side channels.

[FreeBSD Errata Notice FreeBSD-EN-26:30.vfs](https://bsdsec.net/articles/freebsd-errata-notice-freebsd-en-26-30-vfs?utm_source=bsdweekly): A bug in uiomove() causes large file reads to return incorrect byte counts on all supported FreeBSD versions, with patches available for 14.4, 14.5, and 15.1.

[FreeBSD Errata Notice FreeBSD-EN-26:29.tzdata](https://bsdsec.net/articles/freebsd-errata-notice-freebsd-en-26-29-tzdata?utm_source=bsdweekly): FreeBSD has issued an errata notice for an IANA Time Zone Database update affecting all supported versions, with corrections available for stable/15, releng/15.1, stable/14, releng/14.5, and releng/14.4.

[FreeBSD Errata Notice FreeBSD-EN-26:28.watchdog](https://bsdsec.net/articles/freebsd-errata-notice-freebsd-en-26-28-watchdog?utm_source=bsdweekly): FreeBSD has released an erratum notice fixing a compatibility bug in watchdog(4) that can cause spurious system resets when booting a FreeBSD 15 kernel before upgrading the FreeBSD 14 userland.

As always, it's worth following [BSDSec](https://bsdsec.net). [RSS feed](https://bsdsec.net/articles.atom) available.

## Tutorials
[Dual Boot NetBSD 11.1 and Debian 13 on a ThinkPad T14 G1](https://neongd.com/articles/netbsd11-thinkpadt14g1.gmi?utm_source=bsdweekly): A step-by-step walkthrough of installing NetBSD 11.1 alongside Debian 13 on an AMD ThinkPad T14 G1. Covers replacing the unsupported WiFi card, configuring EFI bootloader entries from Linux, and managing display and audio settings.

[FreeBSD GUS: RCU's Cool Cousin](https://gregoire.dev/writing/gus/?utm_source=bsdweekly): An overview of Global Unbounded Sequences (GUS), FreeBSD's epoch-based safe memory reclamation scheme. The article details how GUS uses monotonically increasing sequence numbers alongside the Universal Memory Allocator (UMA) to amortize lock-free memory reclamation, while contrasting FreeBSD's design with Linux RCU and Apple's XNU.

[FreeBSD: How Do You Tackle CVE Security Patch Cadence?](https://klarasystems.com/articles/how-to-tackle-freebsd-cve-security-patch-cadence/?utm_source=bsdweekly): Klara Systems outlines practical strategies for managing FreeBSD security patches across base system advisories and ports, including commands to check running kernel alignment. It also covers upcoming FreeBSD project initiatives to adopt OSV-formatted vulnerability data and SPDX SBOM output.

[Choosing the Right Disks for OpenZFS: HDD, SSD, NVMe](https://klarasystems.com/articles/choosing-the-right-disks-for-openzfs-hdd-ssd-nvme/?utm_source=bsdweekly): Klara Systems compares HDDs, enterprise SATA/SAS SSDs, and NVMe drives for OpenZFS pools across different storage roles. The article covers drive selection traps, such as avoiding SMR disks, setting correct ashift sector sizes, and prioritizing power-loss protection and sustained write endurance over peak benchmarks.
